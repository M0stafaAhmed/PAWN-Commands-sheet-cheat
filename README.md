# PwnRef

A browser-based command reference for penetration-testing workflows, designed for quick lookup and copyable command examples.

> Use these commands only on systems you own or are explicitly authorized to assess.

## Features

- Searchable command reference organized by tool and workflow.
- Copyable command examples.
- Favorites saved in browser storage.
- Export of saved favorites.
- Keyboard-accessible search and responsive navigation.

## Run locally

The application is a static front-end project. Open the included `index.html` in a modern browser, or serve the project directory with a local HTTP server.

## Content quality

Command examples are references, not universal recipes. Check tool versions, target scope, authorization, and command options before execution. Some commands can be disruptive, destructive, or generate substantial network traffic.

## Project status

The repository is being organized and its command catalog is undergoing technical review. Contributions and corrections should include the affected tool/version and a source reference where possible.
